# Git Practice Lab

A small Python task tracker made for learning Git. You do not need to know Python to complete the Git exercises.

## What's inside

- `app.py` — a tiny task-list program
- `tests/test_app.py` — simple tests
- `notes/ideas.md` — a document to edit during practice
- `PRACTICE.md` — the step-by-step Git training mission
- `.gitignore` — example ignore rules

## Run the program (optional)

```bash
python app.py
```

It prints a short task list. You can focus entirely on Git if you prefer.
